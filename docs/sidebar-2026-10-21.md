# Sidebar completion

Implemented local workspace creation/switching with archive-before-replace writes; existing single-workspace storage migrates through the default workspace ID. The canonical active storage key stays compatible. Registry and page identifiers are validated, hierarchy cycles are rejected, stale-tab saves remain blocked, and a failed registry write retains the active workspace.

The sidebar now includes page-specific rename/favorite/duplicate/move/export/trash actions, context-menu keyboard access, drag nesting and ordering, root/favorite/trash drop targets, section collapse and ordering, recent visits, page inventory, search scope/sort, database view shortcuts, and pointer/keyboard width adjustment. Preferences persist per local workspace. Utilities and logout stay visible in desktop and mobile layouts.

Desktop workspace-menu and mobile-sidebar screenshots were visually inspected. The new sidebar suite contains 20 real-browser cases, including cyclic drops, storage failure, unrelated-page deletion, keyboard navigation and reload persistence. Existing editor/database tests remain in the full regression suite. Additional review regressions cover editor/cell focus and imported database preferences.

Limits: these workspaces are browser-local partitions, not account-specific cloud storage. JSON export covers the selected workspace. Native Sites routes handle ChatGPT login/logout; browser tests check links and mocked navigation, not actual identity-provider session invalidation. Real-time collaboration, Notion AI, notifications and full Notion parity are outside the implemented scope.
