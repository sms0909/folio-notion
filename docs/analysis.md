# Notion 화면·기능 분석과 Folio 구현

분석일: 2026-10-20. 분석 도구: tester-army/e2e 0.21.2, @e2e-dev/web 0.15.2, 실제 Chromium.

## 확인한 범위
Notion 공식 도움말 네 페이지를 브라우저로 열고 본문·제목·화면 캡처를 수집했습니다. 연구 테스트는 4/4 통과했습니다. 로그인한 워크스페이스의 동작이나 계정별 최신 기능을 직접 검증한 것은 아닙니다.

| 핵심 구조 | 공식 문서에서 확인한 동작 | Folio의 구현 |
| --- | --- | --- |
| 페이지와 블록 | 문서는 블록을 조합하며 슬래시 메뉴로 콘텐츠 유형 선택 | 페이지 제목, 텍스트·제목·목록·체크박스·인용·콜아웃·구분선, 블록 추가·변환·이동 |
| 사이드바 | 페이지 계층, 즐겨찾기, 설정, 템플릿, 휴지통 | 중첩 페이지 탐색·생성·이동, 즐겨찾기, 복제, 휴지통과 복원 |
| 데이터베이스 | 레코드는 속성을 가진 페이지이며 여러 보기로 표시 | 작업 상세 편집, 상태·우선순위·담당자·마감일, 공유 데이터를 쓰는 표·보드 |
| 검색 | 워크스페이스 검색과 데이터베이스 검색의 범위가 다름 | 페이지 제목·본문 검색, 별도의 작업 속성 검색·상태 필터·날짜 정렬 |

## 디자인 적용
밝은 종이색, 절제된 사이드바, 여백이 넓은 편집 영역, 작은 블록 조작 버튼, 메타데이터 칩을 채택했습니다. Folio 고유의 로고와 추상 풍경 SVG를 만들었으며 Notion의 이미지·로고를 복사하지 않았습니다. 한국어 기본 콘텐츠와 모바일 사이드바를 제공합니다.

## 데이터와 한계
현재 앱은 개인용입니다. localStorage에 문서와 작업을 저장하고 JSON 백업을 내보내거나 가져옵니다. 문서는 Markdown으로 내보냅니다. 계정, 원격 동기화, 실시간 협업, Notion API 연동, AI 모델 기능은 제공하지 않습니다. 데이터베이스의 상세 메모는 일반 페이지 블록과 별도로 구현했습니다.

E2E는 tester-army/e2e의 실제 브라우저·정확한 로케이터 검증을 사용합니다. 자연어 agent.act/agent.assert는 모델 로그인이 필요하므로 사용하지 않았습니다. 테스트 기준을 완화하거나 실행하지 않은 기능을 통과로 처리하지 않습니다.
