# 2026-10-21: 계정 동작과 프로젝트 표 수정

## 재현한 문제

사용자가 지적한 표에서 상태·우선순위·담당자·마감일이 편집 요소가 아닌 표시용 텍스트였습니다. 정렬 버튼은 오름차순과 원래 순서만 바꾸었고, 보기·필터·정렬 상태가 새로고침 뒤 사라졌습니다. 검색창은 입력할 때마다 다시 생성되어 입력 위치 유지가 불안정했습니다. 앱에 로그인·로그아웃을 실행할 경로가 없었습니다.

## 수정

- 표에서 상태·우선순위를 선택하고 담당자·마감일을 직접 편집하며 브라우저에 저장합니다.
- 표·보드 보기, 상태 필터, 정렬 방향을 저장합니다. 정렬은 오름차순·내림차순·해제를 순환합니다. 마감일 없는 작업은 두 방향 모두 마지막에 둡니다.
- 검색창을 재생성하지 않아 키보드 입력과 커서를 유지합니다. 검색 지우기와 빈 결과 안내를 추가했습니다.
- 선택한 상태 필터를 새 작업의 기본 상태로 사용합니다. 새 작업이 현재 검색에 가려지면 검색을 해제해 방금 생성한 작업을 보이게 합니다.
- 사이드바 하단에 항상 보이는 로그아웃 링크와 계정 화면을 추가했습니다. Sites 공식 `/signin-with-chatgpt?return_to=%2F`, `/signout-with-chatgpt?return_to=%2F` 경로로 최상위 탐색합니다.
- 계정 창의 키보드 포커스 순환에 로그인·로그아웃 링크를 포함했습니다.

## 검증

새 동작 7개의 최초 E2E는 7개 모두 실패해 미구현 상태를 재현했습니다. 구현 후 표 동작을 통과했고, 계정 창의 키보드 이동 문제를 추가 실패 테스트로 확인한 뒤 수정했습니다.

최종 실행: `01a15b99-643d-7806-9ead-07bb9270dea4`, tester-army/e2e 0.21.2, Chromium, **41/41 통과**, 실패·스킵 0, 33.16초. `npm run check`도 통과했습니다. 표 편집 화면과 계정 창 캡처를 확인했습니다.

로그아웃 E2E는 링크 경로·최상위 탐색·안내 문구·키보드 접근을 확인합니다. 로컬 서버에 ChatGPT 인증 서버가 없으므로 목적 응답을 테스트에서 모의했습니다. 실제 계정 세션 종료는 Sites 인증 계층의 기능이며, 사용자의 로그인 세션을 임의로 종료해 시험하지 않았습니다.

문서는 기존과 같이 브라우저 localStorage에 저장됩니다. 로그아웃은 브라우저 문서를 삭제하거나 계정별 원격 동기화를 제공하지 않습니다. 이 점을 계정 화면에도 표시했습니다.
