# Folio

Notion의 페이지·블록·검색·데이터베이스 흐름을 참고한 한국어 개인 워크스페이스입니다.

## 실행

Node.js 22.22.3 이상이 필요합니다.

```powershell
npm install
npm run dev
```

http://127.0.0.1:4317 에서 엽니다.

서버는 MariaDB가 필요합니다. `.env.example`을 `.env`로 복사해 DB 값을 채웁니다.

- `npm run dev` — 개발·테스트 모드. `TEST_DB_NAME` DB를 **시작할 때마다 비우고**, 로그인 없이 바로 열리며(브라우저마다 임시 사용자 자동 로그인), Google 대신 테스트용 로그인 화면을 씁니다. `NODE_ENV=production`에서는 켜지지 않습니다.
- `npm start` — 운영 모드. `SESSION_SECRET`, `ADMIN_EMAIL`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`이 없으면 시작하지 않습니다. NAS 설치는 [deploy/README.md](deploy/README.md).

## 로그인

- Google 계정으로만 로그인합니다. 처음에는 `ADMIN_EMAIL` 계정만 들어올 수 있고 그 계정이 관리자가 됩니다.
- 그 뒤로는 관리자가 `/admin`에서 초대한 이메일만 가입할 수 있습니다.
- 모든 계정은 OTP(인증 앱)를 등록해야 하며 로그인할 때마다 6자리 코드를 확인합니다. 로그인은 14일간 유지됩니다.
- OTP 등록 때 복구 코드 10개를 줍니다(각 1회용). 5번 틀리면 15분간 잠깁니다.
- 관리자 화면(`/admin`): 초대·초대 취소, 역할 변경, 사용 중지, OTP 초기화, 감사 기록.
- 관리자 자신의 OTP 초기화: 서버에서 `node server/cli.mjs reset-otp <이메일>` (사용자 목록은 `node server/cli.mjs users`).

## 기능

- 페이지 생성·제목 수정·중첩·이동·복제·즐겨찾기, 아이콘(기본 아이콘·이모지)과 커버, 전체 너비·작은 글씨
- 휴지통 복원·검색·영구 삭제·비우기
- 텍스트, 제목 1~3, 할 일, 글머리·번호 목록, 토글, 인용, 콜아웃, 코드, 구분선, 목차, 페이지 링크 블록
- 굵게·기울임·밑줄·취소선·인라인 코드·링크·글자색·배경색, Markdown 단축 입력
- 슬래시 블록 메뉴, `[[`로 페이지 링크, 백링크, 들여쓰기, 블록 드래그 이동, 실행 취소·다시 실행
- 데이터베이스: 속성(텍스트·숫자·선택·다중 선택·날짜·체크박스·URL 등) 편집, 표·보드·캘린더·갤러리·목록 보기, 필터·정렬·계산, 행을 페이지로 열기
- 내장 템플릿과 내 템플릿(페이지를 템플릿으로 저장)
- 페이지 기록: 페이지를 떠날 때와 편집 중 10분마다 버전 저장, 페이지당 최근 10개, 복원 (이 브라우저에만 보관, 백업 파일 제외)
- 가져오기: JSON 백업, Markdown(새 페이지), CSV(새 데이터베이스) / 내보내기: JSON 백업, Markdown, HTML, CSV, 인쇄
- Google 로그인 + OTP, 초대제 가입, 관리자 화면
- 계정별 워크스페이스 생성·전환, 페이지별 메뉴·드래그 중첩·순서 이동
- 사이드바 너비·접힘·섹션 순서 저장, 최근 방문·전체 페이지·검색 범위와 정렬
- 전체 검색(Ctrl/Cmd+K), 라이트·다크 테마, 서버 자동 저장
- 페이지 주소(`/p/<페이지 id>`), 뒤로·앞으로, 페이지 메뉴의 "링크 복사"

문서는 서버(MariaDB)에 저장됩니다. 고친 내용은 바뀐 부분만 잠시 뒤 서버로 보내고, 그동안은 브라우저에 사본을 둡니다. 서버에 닿지 못하면 "저장 안 됨"을 표시하고 연결되면 다시 보냅니다. 다른 탭이나 기기에서 저장한 내용은 창으로 돌아오거나 30초마다 확인해 화면에 합칩니다(같은 블록을 동시에 고치면 나중에 저장한 쪽이 남습니다. 실시간 공동 편집은 8단계). 로그아웃하면 브라우저 사본을 지웁니다.

페이지 기록은 페이지마다 최근 30개를 서버에 보관하고 저장한 사람을 함께 적습니다.

서버 저장 이전에 이 브라우저에 만들어 둔 문서가 있으면 설정의 "이 브라우저에 있던 문서 → 서버로 옮기기"로 새 워크스페이스로 옮깁니다. 페이지 기록도 함께 옮기며 브라우저의 원본은 지우지 않습니다. 이전 버전 형식(1~3)은 옮길 때 버전 4로 변환합니다.

파일 API(`/api/workspaces/<id>/files`)는 올리기·내려받기·목록·삭제를 제공합니다. 내려받기는 항상 첨부로 보내며 HTML·SVG 등 브라우저가 실행할 수 있는 형식은 받지 않습니다. 화면의 이미지·파일 블록은 9단계에서 붙입니다.

워크스페이스는 계정당 최대 20개입니다. JSON 백업은 현재 선택한 워크스페이스만 내보냅니다. 실시간 협업·공유·AI 기능은 아직 없습니다.

## 검증

```powershell
npm run check
$env:E2E_TELEMETRY_DISABLED='1'
npm run test:e2e
npm run test:research
```

필요한 브라우저: `npx e2e-web install chromium`

로컬 서버가 없으면 E2E 설정이 서버를 시작하고 실행 후 정리합니다. 자연어 모델 API 없이 실제 브라우저 상호작용을 검증합니다. .e2e/report.json에 결과, .e2e/results에 단계별 트레이스와 캡처가 저장됩니다.
