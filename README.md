# Folio

Notion의 페이지·블록·검색·데이터베이스 흐름을 참고한 한국어 개인 워크스페이스입니다.

## 실행

Node.js 22.22.3 이상이 필요합니다.

```powershell
npm install
npm start
```

http://127.0.0.1:4317 에서 엽니다.

## 기능

- 페이지 생성·제목 수정·중첩·이동·복제·즐겨찾기, 아이콘(기본 아이콘·이모지)과 커버, 전체 너비·작은 글씨
- 휴지통 복원·검색·영구 삭제·비우기
- 텍스트, 제목 1~3, 할 일, 글머리·번호 목록, 토글, 인용, 콜아웃, 코드, 구분선, 목차, 페이지 링크 블록
- 굵게·기울임·밑줄·취소선·인라인 코드·링크·글자색·배경색, Markdown 단축 입력
- 슬래시 블록 메뉴, `[[`로 페이지 링크, 백링크, 들여쓰기, 블록 드래그 이동, 실행 취소·다시 실행
- 데이터베이스: 속성(텍스트·숫자·선택·다중 선택·날짜·체크박스·URL 등) 편집, 표·보드·캘린더·갤러리·목록 보기, 필터·정렬·계산, 행을 페이지로 열기
- 내장 템플릿과 내 템플릿(페이지를 템플릿으로 저장)
- 페이지 기록: 페이지를 떠날 때와 편집 중 10분마다 버전 저장, 페이지당 최근 10개, 복원 (이 브라우저에만 보관, 백업 파일 제외)
- 가져오기: JSON 백업, Markdown(새 페이지), CSV(새 데이터베이스) / 내보내기: JSON 백업, Markdown, HTML, CSV, 인쇄
- 계정 화면과 Sites ChatGPT 로그인·로그아웃 연결 (배포 환경)
- 브라우저 내 워크스페이스 생성·전환, 페이지별 메뉴·드래그 중첩·순서 이동
- 사이드바 너비·접힘·섹션 순서 저장, 최근 방문·전체 페이지·검색 범위와 정렬
- 전체 검색(Ctrl/Cmd+K), 라이트·다크 테마, 브라우저 자동 저장

저장 형식은 버전 4입니다. 이전 버전 데이터와 백업은 열 때 자동으로 변환하며, 변환 전 원본은 `folio.workspace.v1.backup`에 남깁니다.

개인용 브라우저 앱입니다. 서버 동기화·실시간 협업·Notion 계정 연동·AI 기능은 없습니다. 브라우저 데이터를 지우기 전에 설정에서 백업을 내보내세요. 다른 기기나 다른 사이트 주소에서는 별도의 저장 공간을 사용합니다.

워크스페이스는 최대 20개이며 같은 브라우저의 문서 공간을 나눕니다. ChatGPT 계정별 저장소가 아니므로 로그아웃해도 문서는 남습니다. JSON 백업은 현재 선택한 워크스페이스만 내보냅니다.

## 검증

```powershell
npm run check
$env:E2E_TELEMETRY_DISABLED='1'
npm run test:e2e
npm run test:research
```

필요한 브라우저: `npx e2e-web install chromium`

로컬 서버가 없으면 E2E 설정이 서버를 시작하고 실행 후 정리합니다. 자연어 모델 API 없이 실제 브라우저 상호작용을 검증합니다. .e2e/report.json에 결과, .e2e/results에 단계별 트레이스와 캡처가 저장됩니다.

분석: [docs/analysis.md](docs/analysis.md). 설계와 계획: docs/superpowers.
